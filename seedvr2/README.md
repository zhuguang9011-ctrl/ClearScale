# ClearScale SeedVR2 独立测试包

这是给 RTX 5060 Ti 8GB 准备的单图验证包，不需要 ComfyUI。它用于判断 SeedVR2 是否比 Finegrain 更适合“AI 商品图高清化、降低塑胶感并尽量保留结构”，目前不是正式版。

1. 完整解压到例如 `D:\ClearScale-SeedVR2`。
2. 双击 **Start.cmd**。首次安装并下载模型会很大，建议预留至少 25GB，保持窗口开启。
3. 安装后会弹出选图窗口。优先选择 400–800px 的代表性局部，包含边缘、孔位、文字或细纹，不要先用整张大图。
4. 固定使用 3B Q4 GGUF、32 层 BlockSwap、CPU 卸载、512px VAE 分块、LAB 颜色校正、零噪声注入。无需手动调参数。
5. 输出保存在原图旁边，文件名含 `_ClearScale_Fidelity_`；结束后自动定位输出文件，并生成验证报告。

启动器会先把图片转换到临时英文路径，规避 Windows/OpenCV 对中文安装目录和中文文件名的兼容问题，完成后再复制回原图目录。完整模型输出写入 `inference.log`；成功或失败后窗口会保留提示，不会无提示关闭。

正式输出采用保真融合：原图的 Lanczos 高清版本作为主体，保留原始颜色、透明度、结构和已有纹理；SeedVR2 仅在边缘方向一致、局部细节能量没有下降的位置，以最高 28% 强度贡献亮度细节。白色线材等模型抹平的区域会自动退回原图。目标短边优先使用精确 2×，最高 2560px，长边最高 4096px。

选图后会显示操作选项：`Fidelity 15%` 最大程度保真，`Balanced 28%` 为默认建议，`Detail 40%` 提供更明显增强，`Raw SeedVR2` 保存模型原始结果用于比较；输出倍率可选 1.5× 或 2×。勾选 `Also save raw SeedVR2 result` 可以同时保存保真结果和模型原始结果。

测试时只判断五件事：孔位/开窗有没有改变、轮廓有没有白边、颜色是否偏移、表面是否仍有涂抹感、细节是否比普通放大更可信。任何一项明显失败，就不进入正式版。

代码来源固定为 [numz/ComfyUI-SeedVR2_VideoUpscaler](https://github.com/numz/ComfyUI-SeedVR2_VideoUpscaler) 提交 `4490bd1f482e026674543386bb2a4d176da245b9`，其代码使用 Apache-2.0。模型会从上游配置的 Hugging Face 仓库自动下载，模型权重许可需以对应模型页面为准。

限制：8GB 预设依赖 CPU 卸载，速度可能较慢；首次下载时间取决于网络。验证报告能证明文件、倍率、颜色与边缘指标，不能单独证明材质审美合格。
