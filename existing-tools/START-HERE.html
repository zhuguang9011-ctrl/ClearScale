采用 Krita AI Diffusion，后台使用 ComfyUI。首次需联网安装运行环境和模型。

  1. 安装 Krita 5（本包插件不用于 Krita 6）。
  2. 打开 Krita → 工具 → 脚本 → 从文件导入 Python 插件，选择本包 krita_ai_diffusion-1.53.0.zip。
  3. 重启 → 设置 → 停靠面板 → AI Image Generation。
  4. Configure → Local Managed Server → NVIDIA/CUDA → 先装 SDXL Photography。
  5. 按中文手册先试换背景，再试线材选区重绘。
